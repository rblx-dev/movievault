# MovieVault

Personal movie and TV discovery site built with **Next.js**, powered by the **TMDB API**, and ready for **Vercel**.

## Features

- Trending films & TV
- Search across movies and shows
- Detail pages with cast, ratings, genres, and trailers

## Setup

1. Copy `.env.example` to `.env.local` and add your TMDB credentials.
2. Install and run:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
